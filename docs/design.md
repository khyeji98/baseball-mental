# 디자인 테마

현재 테마는 **야구장의 스코어카드**를 바탕으로 한 초안이다.
따뜻한 종이색 배경과 그라운드 그린을 사용하고, 스트레스 상승은 번트 오렌지로 표시한다.

## 구성

- `src/theme.ts`: 색상, 간격, 둥근 모서리, 글자 크기 토큰.
- `src/ui.tsx`: 공통 버튼·카드와 화면 스타일.
- 시스템 글꼴을 사용하며 외부 폰트 다운로드 없이 표시한다.
- 게이지와 이벤트는 색상 외에도 숫자·부호·문구로 상태를 전달한다.
- 버튼의 최소 높이는 50pt이며 눌림·비활성 상태를 구분한다.
- 현재 라이트 테마만 제공한다. 다크 모드는 아직 구현하지 않았다.

## 캡처와 출시 이미지

`screenshots/`의 이미지는 실제 앱 코드의 **모바일 크기 웹 렌더링**을 캡처한 디자인 검토용이다.
네이티브 기기 캡처나 스토어 제출 이미지로 취급하지 않는다.

정식 출시 전에는 확정된 화면을 iOS·Android 대상 기기에서 다시 캡처한다.
홈 → 경기 중 멘탈 변화 → 경기 결과 → 시즌 통계를 주요 장면으로 계획하되,
아직 구현되지 않은 기능은 출시 이미지에 포함하지 않는다.
각 스토어의 제출 시점 이미지 규격을 확인하고, 실제 기능과 일치하는 설명을 사용한다.
